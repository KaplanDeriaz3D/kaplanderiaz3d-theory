# KaplanDeriaz3D — Theory

Theory notebooks (MATLAB Live Scripts) and supporting documentation for the hydrodynamic design methodology behind [KaplanDeriaz3D](https://github.com/KaplanDeriaz3D): blade angle and head calculations for Kaplan and Deriaz turbines, based on the Euler equation and velocity triangles applied to axial and diagonal-flow runners.

See [kaplanderiaz3d-matlab](https://github.com/KaplanDeriaz3D/kaplanderiaz3d-matlab) and [kaplanderiaz3d-python](https://github.com/KaplanDeriaz3D/kaplanderiaz3d-python) for the design application implementing this methodology.

## Contents

- `Master_thesis_Deriaz_design_English_Version.pdf`  — English translation of the original masters thesis written in spanish, covers the theoretical basis of the project
- `Trabajo_fin_de_Master_Diseño_Deriaz_Castellano.pdf`  — Original masters thesis document written in spanish
- `Kaplan_Angulos_Alturas2.mlx` — blade angle and head calculation for the Kaplan (axial) case, developed as a pedagogical and validation baseline before extending the methodology to the diagonal-flow case.
- `Deriaz_Angulos_Alturas2.mlx` — blade angle and head calculation for the Deriaz (diagonal-flow) case.

# KaplanDeriaz3D — Theory

Theory notebooks (MATLAB Live Scripts) and supporting documentation for the hydrodynamic design methodology behind [KaplanDeriaz3D](https://github.com/KaplanDeriaz3D): blade angle and head calculations for Kaplan and Deriaz turbines, based on the Euler equation and velocity triangles applied to axial and diagonal-flow runners.

See [kaplanderiaz3d-matlab](https://github.com/KaplanDeriaz3D/kaplanderiaz3d-matlab) and [kaplanderiaz3d-python](https://github.com/KaplanDeriaz3D/kaplanderiaz3d-python) for the design application implementing this methodology.

## Contents

- `Deriaz_Angulos_Alturas2.mlx` — blade angle and head calculation for the Kaplan (axial) case, developed as a pedagogical and validation baseline before extending the methodology to the diagonal-flow case.
- `Deriaz_Angulos_Alturas2.mlx` — blade angle and head calculation for the Deriaz (diagonal-flow) case, applied to a real hydropower site (Central Hidroeléctrica de Saucelle II, Spain).

## About this project

This methodology and the accompanying software were developed as part of a Master's Thesis (TFM) on hydraulic machinery design. The full thesis document will be added to this repository once it has been reviewed and approved.
